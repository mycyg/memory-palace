# Historical benchmark data

The [2.0 synthetic work-memory report](work-memory-v2.md) and its [before](work-memory-v2-before.json) and [after](work-memory-v2-after.json) raw data use one fixed, model-free corpus. They record a single run on the stated machine and are not CI performance thresholds.

The other JSON reports in this directory belong to the [MemoryPalace 1.x performance report](../performance.md). They are historical measurements using different fixtures.
